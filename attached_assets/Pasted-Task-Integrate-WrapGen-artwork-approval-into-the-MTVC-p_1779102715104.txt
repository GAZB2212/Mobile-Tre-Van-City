Task: Integrate WrapGen artwork approval into the MTVC platform

We have a separate tool called WrapGen (hosted at its own domain) that generates AI van wrap mockups and sends proof links to customers. When a customer clicks "Approve Artwork" on their proof link, WrapGen records the approval and fires a webhook. Your job is to wire that into MTVC so staff can see approval status on quotes.

What WrapGen provides

API base URL: https://<wrapgen-domain>.replit.app
API Key: wg_f1c337e020d255fd468aacbb29513f8496a45c9242b22327
Auth header on every request: Authorization: Bearer wg_f1c337e020d255fd468aacbb29513f8496a45c9242b22327

Endpoints available:

GET  /api/v1/previews            → list all previews (?approved=true|false to filter)
GET  /api/v1/previews/:id        → get status of one preview (approved, approvedAt, approvedByName, previewUrl)
POST /api/v1/previews            → create a new preview link from MTVC

POST /api/v1/previews body:

{
  "customerName": "John Smith",
  "vanModel": "Ford Transit",
  "wrapType": "full-wrap",
  "backgroundLabel": "Urban Street",
  "frontImage": "data:image/jpeg;base64,...",
  "rearImage":  "data:image/jpeg;base64,...",
  "sideImage":  "data:image/jpeg;base64,..."
}

Returns: { id, previewUrl, expiresAt }

Webhook — WrapGen will POST to MTVC_WEBHOOK_URL the moment a customer approves. Payload:

{
  "event": "artwork.approved",
  "previewId": "uuid",
  "customerName": "John Smith",
  "approvedByName": "John Smith",
  "approvedAt": "2026-05-18T11:30:00.000Z",
  "vanModel": "Ford Transit",
  "wrapType": "full-wrap",
  "previewUrl": "https://wrapgen.../preview/uuid",
  "sentAt": "2026-05-18T11:30:00.000Z"
}

What to build in MTVC

Database — add two columns to the quotes table (or a new artwork_proofs table if cleaner): wrapgen_preview_id (text), artwork_approved_at (timestamp), artwork_approved_by (text).
Quote detail page — in the admin quote detail view, add a "Wrap Artwork" section:
If no proof has been sent yet: a "Send Artwork Proof" button. When clicked, POST to WrapGen /api/v1/previews with the customer name, van model, wrap type, and any generated images stored on the quote. Save the returned previewId against the quote. Show the previewUrl as a copyable link staff can send to the customer.
If a proof has been sent but not yet approved: show the proof link, a status badge "Awaiting Approval", and a "Check Status" button that polls GET /api/v1/previews/:id.
If approved: show a green "Artwork Approved" badge with the approver's name and timestamp.
Webhook endpoint — create POST /api/webhooks/wrapgen (public, no auth required). When it receives an artwork.approved event, look up the quote by wrapgen_preview_id, set artwork_approved_at and artwork_approved_by, and (optionally) advance the quote status or add an admin note. Store MTVC_WEBHOOK_URL=https://<mtvc-domain>/api/webhooks/wrapgen in your environment and share it so it can be configured in WrapGen's environment as MTVC_WEBHOOK_URL.
Artwork approvals list — add a tab or page at /admin/artwork-approvals listing all quotes with a proof sent, sorted by most recent, showing approval status at a glance.
Environment variables to add to MTVC:

WRAPGEN_API_KEY=wg_f1c337e020d255fd468aacbb29513f8496a45c9242b22327
WRAPGEN_API_URL=https://<wrapgen-domain>.replit.app

Environment variable to add to WrapGen (once MTVC is deployed):

MTVC_WEBHOOK_URL=https://<mtvc-domain>.replit.app/api/webhooks/wrapgen
